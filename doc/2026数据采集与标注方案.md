# 2026 数据采集与标注方案

> 目标：采集本届比赛真实场景数据，重新训练 YOLO11-seg 模型。
> 原则：**操场拍摄优先，小场景为辅；一次操场尽量采全。**

---

## 一、需要拍摄的类别

根据 2026 规则，建议采集：

| 类别 | 标注类型 | 目标数量 | 场景 |
|---|---|---|---|
| left_lane | 分割 Mask | ≥300 | 直道、弯道、内外道 |
| right_lane | 分割 Mask | ≥300 | 直道、弯道、内外道 |
| track | 分割 Mask（可选） | ≥200 | 跑道可行驶区域 |
| grass | 分割 Mask（可选） | ≥200 | 草坪/非可行驶区域，重点内道 |
| blue_barrier | 检测框 / 分割 | ≥200 | 发车挡板、停车区挡板 |
| crosswalk | 检测框 / 分割 | ≥200 | 斑马线 |
| traffic_light_red | 检测框 | ≥200 | 红灯状态 |
| traffic_light_green | 检测框 | ≥200 | 绿灯状态 |
| obstacle_cone_blue | 检测框 | ≥200 | 蓝色锥桶 |
| obstacle_cone_red | 检测框 | ≥200 | 红色锥桶 |
| parking_zone | 分割（可选） | ≥200 | 上下停车区、被挡/未挡 |

> 如果跑道是蓝色底，则锥桶用红色；如果跑道是红色底，则锥桶用蓝色。采集时按实际场地颜色准备。

## 二、采集建议

### 1. 使用小车摄像头
```bash
cd /root/dev
python3 scripts/capture_dataset.py --output /root/dataset/lane --interval 0.5
```

### 2. 场景清单

- 发车区：蓝板存在 / 蓝板消失；
- 切换区；
- 直道巡线；
- 弯道巡线；
- 内道/草坪边界；
- 斑马线前、斑马线上；
- 红绿灯红灯、绿灯；
- 锥桶左/中/右；
- 停车区：上区被挡、下区被挡、未挡。

### 3. 拍摄数量

- 每个类别建议 **200~300 张**；
- 总数据量建议 **1500~3000 张**；
- 宁可少而精，不要大量重复无意义图片。

---

## 三、标注工具

推荐：

- **LabelImg**：适合检测框；
- **Roboflow**：适合在线标注、导出 YOLO 格式；
- **Ultralytics 标注工具**：适合分割多边形标注；
- **X-AnyLabeling / Labelme**：适合分割 Mask。

标注格式：

```text
YOLO 格式
images/
labels/
data.yaml
```

## 四、数据集目录结构


## 五、INT8 校准图片

- 在 RKNN INT8 量化时需要 10~50 张校准图片；
- 校准图片应来自**真实赛道场景**；
- 可以用采集脚本额外拍一组：
  ```bash
  python3 scripts/capture_dataset.py --output /root/dataset/calib --interval 0.5
  ```
- 之后在服务器转换时生成 `dataset.txt`，每行写一张校准图片路径。

## 六、Hard Case 重点

- 内道草坪边界；
- 阴影；
- 逆光；
- 红/蓝跑道；
- 雨天/阴天（如果可能）；
- 摄像头角度偏差。
