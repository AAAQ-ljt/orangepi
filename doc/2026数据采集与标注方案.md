# 2026 数据采集与标注方案

> 目标：采集本届比赛真实场景数据，重新训练 YOLO11-seg 模型。
> 原则：**操场拍摄优先，小场景为辅；一次操场尽量采全。**

---

## 一、需要拍摄的类别

根据最终方案，**第一版优先采集赛道元素**，车道线/跑道/草坪作为可选兜底。

### 第一版必采（模型识别特殊元素）

| 类别 | 标注类型 | 目标数量 | 场景 |
|---|---|---|---|
| blue_barrier | 检测框 | ≥200 | 发车挡板、停车区挡板 |
| crosswalk | 检测框 | ≥200 | 斑马线 |
| traffic_light_red | 检测框 | ≥200 | 红灯状态 |
| traffic_light_green | 检测框 | ≥200 | 绿灯状态 |
| obstacle_cone_blue | 检测框 | ≥200 | 蓝色锥桶 |
| obstacle_cone_red | 检测框 | ≥200 | 红色锥桶 |
| parking_zone | 检测框/分割（可选） | ≥200 | 上下停车区、被挡/未挡 |

### 可选/后期（用于异常兜底）

| 类别 | 标注类型 | 目标数量 | 说明 |
|---|---|---|---|
| left_lane / right_lane | 分割 Mask | 按需 | 模型兜底车道 |
| track | 分割 Mask | 按需 | 可行驶区域 |
| grass | 分割 Mask | 按需 | 草坪/非可行驶区域，重点内道 |

> 第一版优先保证 OpenCV 巡线 + 特殊元素识别；track/grass 等分割类别可以等主流程跑通后再补充。

## 二、采集建议

### 1. 使用小车摄像头
```bash
cd /root/dev
python3 scripts/capture_dataset.py --output /root/dataset/lane --interval 0.5
```

### 2. 场景清单

- 发车区：蓝板存在 / 蓝板消失；
- 切换区；
- 直道巡线；
- 弯道巡线；
- 内道/草坪边界；
- 斑马线前、斑马线上；
- 红绿灯红灯、绿灯；
- 锥桶左/中/右；
- 停车区：上区被挡、下区被挡、未挡。

### 3. 拍摄数量

- 每个类别建议 **200~300 张**；
- 总数据量建议 **1500~3000 张**；
- 宁可少而精，不要大量重复无意义图片。

---

## 三、标注工具

推荐：

- **LabelImg**：适合检测框；
- **Roboflow**：适合在线标注、导出 YOLO 格式；
- **Ultralytics 标注工具**：适合分割多边形标注；
- **X-AnyLabeling / Labelme**：适合分割 Mask。

标注格式：

```text
YOLO 格式
images/
labels/
data.yaml
```

## 五、INT8 校准图片

- 在 RKNN INT8 量化时需要 10~50 张校准图片；
- 校准图片应来自**真实赛道场景**；
- 可以用采集脚本额外拍一组：
  ```bash
  python3 scripts/capture_dataset.py --output /root/dataset/calib --interval 0.5
  ```
- 之后在服务器转换时生成 `dataset.txt`，每行写一张校准图片路径。

## 六、Hard Case 重点

- 内道草坪边界；
- 阴影；
- 逆光；
- 红/蓝跑道；
- 雨天/阴天（如果可能）；
- 摄像头角度偏差。
