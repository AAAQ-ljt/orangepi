# 2026 模型训练与 RKNN 部署方案

> 本文档定义本届比赛模型的训练、导出、INT8 量化和部署流程。
> 目标：在 Python 架构下达到 **15~25 FPS**，暂不转 C++。

---

## 一、模型选型

| 项 | 选择 |
|---|---|
| 框架 | **Ultralytics YOLO** |
| 模型 | **YOLO11-seg**（YOLO11n-seg 或 YOLO11s-seg） |
| 是否使用 YOLOv5 | 否 |
| 输入尺寸 | 640×640 |
| 部署格式 | RKNN INT8 |
| 目标平台 | RK3588 |

---

## 二、训练流程

### 1. 准备数据

数据要求见 `doc/2026数据采集与标注方案.md`。

### 2. 训练命令示例

```bash
# 使用 YOLO11n-seg 预训练模型
yolo detect train data=datasets/smartcar2026/data.yaml model=yolo11n-seg.pt epochs=200 imgsz=640 batch=16 device=0
```

或者用 Python：

```python
from ultralytics import YOLO

model = YOLO("yolo11n-seg.pt")
model.train(
    data="datasets/smartcar2026/data.yaml",
    epochs=200,
    imgsz=640,
    batch=16,
    device=0,
    name="smartcar2026_n",
)
```

如果精度不够，可换 `yolo11s-seg.pt`。

## 三、导出 ONNX

```python
from ultralytics import YOLO

model = YOLO("runs/smartcar2026_n/weights/best.pt")
model.export(format="onnx", imgsz=640, opset=12, simplify=True)
```

导出参数建议：

```text
Image Size: 640
Batch Size: 1
Precision: FP32（导出 ONNX 用 FP32，RKNN 阶段再量化）
Dynamic: False
Simplify: True
Opset: 12
NMS: 关闭（Unfiltered predictions）
```

## 四、RKNN INT8 转换

### 4.1 校准图片

INT8 量化需要校准图片：

- 数量：10~50 张；
- 来源：真实操场/赛道场景；
- 准备 `dataset.txt`，每行一张图片路径。

### 4.2 转换脚本

在服务器（x86 Linux / ModelScope GPU 环境）执行：

```bash
python convert_rknn.py \
  --onnx best.onnx \
  --output best_int8.rknn \
  --platform rk3588 \
  --quantize \
  --dataset dataset.txt
```

### 4.3 如果使用 Ultralytics 平台

- 平台导出 RKNN 时选择 **INT8**；
- 如果平台不支持配置校准图片，建议使用 RKNN-Toolkit2 本地/服务器转换；
- 参考：https://docs.ultralytics.com/integrations/rockchip-rknn

### 4.4 精度检查

- 转换后在小车上用 `vision/debug_view.py` 或 `vision_main.py --debug` 验证；
- 如果 INT8 掉精度严重：
  - 使用混合量化；
  - 或退回 FP16 RKNN。
