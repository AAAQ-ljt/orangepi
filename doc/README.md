# doc 文档地图

> 建立于 2026-09-15（文档结构性整理后）。**先看这张表再打开具体文档**，避免翻到已过时的版本。

## 四、维护约定

1. **设计变了** → 改 `具体实施方案.md`（并在 §11 变更记录加一行）；**计划变了** → 改 `执行路线图.md`；**别再往一处堆**。
2. **类别表是契约**：`具体实施方案.md` §3.1.3 与 `数据与模型方案.md` §1 必须一致，改一处就要同时改另一处。
3. 新增元素专项 → 放 `专项方案/`，并在本文件第二节登记。
4. 文档里的路径引用请用**相对 `doc/` 的路径**，不要在正文里写 `doc/xxx.md` 之外的绝对路径。
