## C-001 蓝锥桶 HSV 阈值/ROI 扫描标定工具

**产出**：`dev/scripts/diag/cone_hsv_sweep.py`（网格扫 H/S/V + ROI 上沿，官方三配方对照）。

**关键发现（离线实锤"蓝锥识别率 0"的根因）**：
- `CONE_GATE_ROI` 上沿 0.35 → 数据集照片里锥桶 98.4% 蓝像素在 y<168，**整个被 ROI 切掉**；
- V≥150 门槛偏高（数据集锥桶 V 中位 176~178，部分帧更低）；
- 修复候选：HSV (85,55,55)~(125,255,255) + ROI_top=0.05 → 正样本 80 张检 62（77.5%）；
- "误检 76%"实为负样本污染：logs_pull 里含蓝板帧（发车/停车阶段），板被当锥桶。

**复现**：
```bash
PYTHONPATH=dev python scripts/diag/cone_hsv_sweep.py \
  --pos-dir "train/project/蓝色锥桶1" --pos-dir "train/project/蓝色锥桶2" \
  --neg-dir "../logs_pull" --limit 40
```
**待办（现场）**：实拍帧回来后复跑；决定 settings 里 CONE_GATE_ROI / CONE_BLUE_HSV_* 的最终值。
