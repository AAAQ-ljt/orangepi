## 场地几何（2026-09-15 按规则初稿插图核对确认）

```text
        行驶方向 ──▶
  ┌──────────────┬──────────────┐
  │  上格（左）   │  ✕ 蓝板挡住   │   ← 蓝板立在"入口边"（车先到达的那条边）
  ├──────────────┼──────────────┤   ← 这条横线 = 赛道中线（沿行驶方向）
  │  下格（右）   │  ✅ 停这里    │
  └──────────────┴──────────────┘
        整块停车区 = 1m（沿行驶方向）× 赛道宽
```

| 结论 | 说明 |
|---|---|
| **两格是相对行驶方向的左右并排**（图上是"上下"） | 不是前后排列 → **判定要比 `board_x` 与外框中点**，不是 `board_y` |
| 分格线 = 沿行驶方向的赛道中线 | 由**几何推算**（外框中点 / IPM），**不靠检测**——裁判可能把板压在中线上 |
| 蓝板立在某格入口边 | 板不一定盖满整格 → 感知只需回答"板在哪一侧" |
| 车本来就骑在中线上进场 | 所以入位本质是"**横向让开半格 + 把四轮落进 1m 长的格子**"，不是倒库 |

## 结论

不要把停车位标注成“左停车位”和“右停车位”两个类别。推荐采用：

```text
模型检测蓝色挡板
→ 几何方法判断挡板位于左侧还是右侧
→ 选择另一侧停车位
→ 低速轨迹跟踪入库
```

## 1. 修改标注方式

当前左右分类配合 Roboflow 的 `fliplr=0.5` 会产生错误标签：图片翻转后左右位置交换，但类别不会自动交换。

建议只保留一个类别：

```yaml
0: blue_barrier
```

合并类别后可以继续使用水平翻转增强。

## 2. 判断哪个车位被挡

检测蓝色挡板后，使用检测框的**底边中心**：

```python
cx = (x1 + x2) / 2
yb = y2
```

根据同一高度处的赛道左右边界计算相对位置：

```python
ratio = (cx - x_left) / (x_right - x_left)

if ratio < 0.45:
    target_slot = "right"   # 左侧被挡
elif ratio > 0.55:
    target_slot = "left"    # 右侧被挡
else:
    target_slot = "unknown"
```

不要直接用 `cx < 图像宽度 / 2` 判断，因为车辆可能斜着进入停车区。

条件允许时，可用单应性变换把挡板底边中心投影到俯视图，再判断它落入哪个停车区多边形。

## 3. 停车区域如何识别

采用组合方案：

- 状态机：完成红绿灯和双锥桶任务后，进入停车阶段；
- 检测模型：识别蓝色挡板；
- OpenCV或车道算法：识别赛道边界、黄色入口线和中间分隔线；
- 几何算法：判断挡板在哪个停车区域。

蓝色挡板在切换区和停车区都会出现，应通过状态机区分：

```text
WAIT_START_BARRIER_REMOVED：挡板移除后自主发车
PARKING_APPROACH：根据挡板位置选择开放车位
```

## 4. 提高判断稳定性

不能根据单帧结果立即选择车位。建议：

- 连续5～10帧判断结果一致；
- 设置置信度阈值；
- 设置 `0.45～0.55` 不确定区；
- 车位一旦确认就锁定，不再左右切换；
- 判断不清时在分流点前减速或停车，不能随机选择。

## 5. 入库和停车

停车控制分为：

```text
PARKING_APPROACH
→ SLOT_CONFIRM
→ ALIGN_TO_SLOT
→ ENTER_SLOT
→ FINAL_STOP
```

- 根据开放车位的左右边界计算中心线；
- 生成从当前车道中心到车位中心的平滑轨迹；
- 使用 Pure Pursuit、Stanley 或带前馈的 PID 跟踪，不要用检测框直接控制舵机；
- 入库阶段低速行驶并限制舵角变化率；
- 使用黄色终点线、单应性距离和编码器共同判断停车位置；
- 目标是让车身停在停车区中部，确保四个轮子全部进入区域。

## 6. 最小可行方案

```text
单类蓝挡板检测
+ 左右赛道边界识别
+ 相对横向坐标判断
+ 连续7帧投票
+ 锁定开放车位
+ 低速中心线跟踪入库
+ 黄线与编码器联合停车
```

该方案比训练“左停车位/右停车位”更简单，也不会受到水平翻转标签错误的影响。

## 八、停车
YOLO只负责回答“哪个车位可停”，真正把车准确停进去，建议采用“停车线几何定位+分阶段闭环控
制”，不要让YOLO直接输出方向盘控制量。
推荐流程：
1. YOLO检测蓝色挡板，确定目标车位。
2. 在目标车位ROI内提取停车框两侧边线和末端横线。
3. 通过相机标定和IPM透视变换，把图像转换为俯视图。
4. 计算目标车位：
○ 中心线；
 车辆相对中心线的横向偏差 ey；
车辆与车位方向的航向偏差e₃ψ;
。 车辆到末端停车线的距离d。
5. 用状态机分阶段完成停车。
