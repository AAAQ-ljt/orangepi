# 锥桶识别与 S 型避让方案（P1-3 雏形，2026-09-23 落地）

## 1. 一句话目标

循迹途中遇到**两个蓝色锥桶（暂定放跑道中间）**，模型/颜色检测识别后走
**S 型（左绕→回正→右绕）**绕过去，继续循迹，直到再次见到蓝板停车。

完整任务链（与 `lane_ref_test.py` 现有流程衔接，安全信封复用 `bench_common.MotorSession`）：

```text
清空手动操控进程（MotorSession：停 opi-control）
  → 起步前自检（选带/前瞻带/目标点，不通过不发车）
  → 蓝板出现 → StartGate 边沿武装
  → 蓝板移开 → 发车
  → 循迹（P1-1 参考实现版，全护栏）
  → 检测到锥桶（hsv/模型，防抖 3 帧）→ S 型避让：avoid1 左绕 → resume 回正
    → avoid2 右绕 → 回 track（两个锥桶先后触发两轮，天然 S 轨迹）
  → 再次看到蓝板 → 立即停车
  → 恢复手动操控进程（MotorSession 退出：opi-control + 图传逐项验证）
```

## 2. 文件与职责

| 文件 | 职责 |
|---|---|
| `dev/vision/cone_detect.py` | 检测器：`detect_cones_hsv()`（蓝色连通域多候选）+ `ConeDetector`（hsv/model 双通道）+ `ConeTracker`（进出防抖）。本地无权重可跑 |
| `dev/config/settings.py` | `CONE_*` 常量集中（HSV 阈值/框闸门/绕行时长/舵角/油门） |
| `dev/scripts/lane_ref_test.py` | 参数 `--cone-method hsv` + `--cone-avoid`；主循环 S 型相位机（avoid1/resume/avoid2）；CSV 相位列直接记录；`--image` 单图模式输出锥桶框 |
| `dev/scripts/cone_check.py` | 本地批量验证：正样本（train 锥桶图）检出率 + 负样本误检率 |
| `dev/tests/test_cone_detect.py` | 合成图单测（检出/双桶/小噪声/大板/防抖） |
| `dev/tests/test_lane_ref_run.py` | 端到端：假摄像头 + 锥桶帧走完整状态机（+2 项） |

**检测通道**：
- `hsv`：HSV 蓝色 (70,30,50)~(145,255,255) + 开运算 + 连通域多候选 + 闸门
  （w∈[25,360]、h∈[40,420]、h≥0.5w、面积占比 ∈[0.002,0.15]）。**参考实现同源**（oldCode
  `blue()`+`Obstacles()`），本地图片可验证；锥桶蓝色比挡板浅（实测 S 中位 63~72 vs 挡板 ≥80），
  阈值独立，**不可**复用 START_BLUE_HSV。
- `model`：`ConeDetector(method="model", model_path=...)` 走 RKNN car4cls 的 coneBucket 类
  （双进程架构里由视觉进程给，本脚本暂用 hsv）。加载失败自动回退 hsv。

## 3. 检测判据与实测效果（2026-09-23 本地验证）

### 3.1 为什么不用挡板那套阈值

训练集（`train/project/蓝色锥桶1/2`，共 907 张）实测：

| 量 | 锥桶 | 挡板 |
|---|---|---|
| HSV H 中位 | 90~96 | 95~135 区间 |
| HSV S 中位 | 63~72（偏浅） | ≥80（深） |
| 直接套挡板阈值 (95,80,60) | 蓝色像素占比 1.2%（漏大半） | 正常 |

### 3.2 闸门口径（640×480）

参考实现是 320×240：`w>50 && h>70` → 按同物理尺寸折算到 640 宽的我们这版在
`CONE_MIN_W=25 / CONE_MIN_H=40`（覆盖训练图里最远的 ~26×75 小锥桶）。
上限 `CONE_MAX_W=360 / CONE_MAX_H=420 / MAX_AREA=0.15` 挡住"近处大蓝板/大蓝物"；
`h < 0.5w` 的**扁平蓝条**（反光带/板底边）直接丢弃。

### 3.3 本地批量验证结果

| 集 | 张数 | 检出率 | 说明 |
|---|---|---|---|
| 蓝色锥桶1（手持近拍，锥桶偏左上/远端小） | 475 | 73.7% | 全图口径；漏检多为 <25px 的极小锥桶 |
| 蓝色锥桶2（手持，锥桶右上较近） | 432 | 86.1% | 全图口径 |
| logs_pull 巡线帧（无锥桶，默认 ROI） | 74 | 误检 8.1% | 多为 yb=480 底边蓝块/杂物 |

注意：训练图是**手持朝前拍**（锥桶在 y≈90~180），而部署是**下摄**（锥桶在画面中下部，
默认 ROI `CONE_GATE_ROI=(0.10,0.90,0.35,1.00)` 内）——所以正样本验证用全图口径，
部署口径按 ROI。**操场上首件事是确认锥桶出现在 ROI 内**（`lane_probe --camera 2` 看）。

误检代价评估：避让动作是**低速（1548us 维持档）短暂绕行**，误触发一次损失小；
漏检撞锥 +20s 且可能卡住——**宁可误检不可漏检**，阈值先放松，现场按误检率再收紧。

## 4. S 型绕行相位机（lane_ref_test 主循环内）

```text
track 中 ConeTracker 连续 CONE_HYSTERESIS_FRAMES(3) 帧有锥桶
  → cone_phase = avoid1：舵角 center ± sign*AVOID_DEG（默认 20°，first 侧），持续 CONE_AVOID_S(1.2s)
  → resume：回中直行 CONE_SEGUE_S(0.8s)（等第二个锥桶/穿过中线）
  → avoid2：反向绕 CONE_AVOID_S
  → 结束：tracker.reset()，回 track（两个锥桶间隔出现 → 自然触发两轮 = S 形）
```

安全细节：
- 绕行期间**豁免跑偏保护/画龙检测**（故意的大幅转向，否则一绕就误触发停车）；保留
  `--max-seconds` 总上限 + 再见板立即停车（driving=False 分支天然覆盖）。
- 绕行油门 `CONE_AVOID_US=1548`（>死区 1545 才转，又比循迹慢）——低速绕行，失控代价小。
- 绕行时长、舵角、first 方向全部参数化（`--cone-avoid-deg/-s/--cone-resume-s/--cone-first-dir`），
  现场按实车转向半径调。
- `--cone-avoid` 默认**关**：纯循迹复测行为与之前完全一致（有测试保证）。

## 5. 使用方式

```bash
# 本地：单图看锥桶检测（中文路径也能读）
cd dev && PYTHONPATH=. python scripts/lane_ref_test.py --image "train/project/蓝色锥桶2/xxx.jpg"

# 本地：批量验证检出率/误检率
PYTHONPATH=dev python scripts/cone_check.py \
    --pos-dir "train/project/蓝色锥桶1" --pos-dir "train/project/蓝色锥桶2" \
    --neg-dir logs_pull --limit 60 --save-samples logs_pull/cone_check

# 车上：实验室先验检测（★推荐第一步）：蓝板发车 → 前进 → 检测到锥桶就停车，
#       锥桶移开可继续前进；不绕行
sudo python3 /root/dev/scripts/lane_ref_test.py --cone-method hsv --cone-stop \
    --allow-motion --max-seconds 120

# 车上：锥桶 S 型避让实跑（检测确认没问题之后再上）：
sudo python3 /root/dev/scripts/lane_ref_test.py --cone-method hsv --cone-avoid \
    --allow-motion --max-seconds 120

# 复盘：拉会话目录回本地跑 --replay（相位 avoid1/resume/avoid2/cone_stop 都在 CSV 里）
```

实验室测 `--cone-stop` 时观察点：
1. 锥桶要放进下摄 ROI（画面中下部，`CONE_GATE_ROI` 是 y∈[168,480]），放太高会看不到；
2. 看终端 `锥桶 N 个：x=… yb=…` 打印是否出现（防抖 3 帧后触发停车）；
3. 停车后把锥桶移开，车应自动继续前进（`▶️ 锥桶已移开 → 继续前进`）；
4. 停车期间日志应出现 `🛑 检测到锥桶 → 停车`。

## 5b. 相位机（--cone-stop 实验室模式）

与"再见板停车"同款设计：**不置 `stopped`**（那会退出整个循环），而是让 `driving=False`
停车——锥桶防抖消失后自动恢复前进。绕行（--cone-avoid）默认关时检测到锥桶**只记录不停车**。

## 6. 现场待标定项（由实跑决定）

1. `CONE_AVOID_DEG`（默认 20°）：绕行幅度——车转向半径小就加大，否则减小；
2. `CONE_AVOID_S`（默认 1.2s）与 `CONE_SEGUE_S`（0.8s）：绕行/穿越时长——看第二次锥桶
   触发的时机，S 两端要对齐两个锥桶的间隔；
3. `CONE_BLUE_HSV_*`：操场光照下蓝阈值可能要微调（用 `cone_check` 的叠加图确认）；
4. `CONE_GATE_ROI`：确认锥桶在下摄 ROI 内（先 `lane_probe --camera 2`）。
