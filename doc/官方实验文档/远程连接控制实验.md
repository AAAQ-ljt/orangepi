# **香橙派小车远程连接与网页控制**

## **实验目的**

1、掌握通过串口使用 MobaXterm 连接 OriginPi 5 小车的操作流。

2、学会查询小车 IP 地址，建立 SSH 远程网络连接。

3、熟悉小车网页远程控制平台，理解网页端操控小车、云台的操作方法。。

4、区分串口本地连接与SSH 网络远程连接两种连接方式的作用与区别。

## **实验内容**

1、使用串口线连接电脑与 OriginPi 5 小车，配置 MobaXterm 串口会话登录系统。

2、在终端执行命令查询无线网卡 IP 地址。

3、使用 IP 新建 SSH 会话，实现网络远程登录小车。

4、在浏览器打开小车远程控制网站，熟悉网页控制面板功能，完成小车与云台操控。

## **实验仪器**

1、OriginPi 5 智能小车整机。

2、USB 转串口调试线(CH340)。

3、安装 MobaXterm 软件的电脑。

4、浏览器（Edge/Chrome）

## **实验原理**

1、**串口连接**：串口调试线直接建立电脑与香橙派硬件通信，不依赖网络，在没有无线网络时，作为基础调试手段，用于初始化配置、查看开机日志。

2、**SSH 远程连接**：基于无线网络 TCP 通信，通过 IP 地址远程登录小车 Linux 系统，可以远程传输文件、运行程序，是日常开发调试主要方式。

3、**网页远程控制**：小车后端开启 Web 服务，通过公网域名转发，浏览器访问网页，通过 WebSocket 双向通信下发油门、转向、云台控制指令，同时回传摄像头实时视频画面，实现可视化远程操控。

## **实验步骤**

**一、串口连接小车（MobaXterm Serial 模式**

1 将 USB 转串口线一端接入电脑 USB，另一端连接 OriginPi 5 串口引脚，给小车上电。

2 打开 MobaXterm 软件，点击左上角 Session → Serial。

3 在配置界面选择正确的串口端口（在电脑设备管理器中查询 COM 编号）。

4 波特率（Speed）设置为 1500000，其余参数保持默认，点击 OK 建立串口连接。

5 等待系统启动完成。

 

**二、查询无线网卡 IP 地址**

在串口终端中输入命令：

ip addr show

查找无线网卡对应的 inet 字段，记录小车局域网 IP 地址。

**三、建立 SSH 远程连接**

1 在 MobaXterm 点击 Session → SSH。

2 Remote host 填入上一步获取的小车 IP 地址。

3 pecify username 勾选，用户名填写：root。

4 点击 OK 发起连接，输入密码：orangepi，完成 SSH 远程登录。

串口连接适合无网络环境调试；SSH 连接依靠无线网络，支持文件传输、长期程序运行。

**四、网页端远程控制小车**

1 打开电脑浏览器，在地址栏输入小车远程控制网址，示例：

<https://car0003.smartcar.run(0003>为自己小车分配的号码)

2 页面加载完成后，观察顶部状态栏，确认WS:已连接，代表网页与小车通信链路建立成功。

3 面板功能操作说明：

1）左侧【油门】滑块：上下拖动控制小车前进、后退；滑块在最下方为停止，界面显示停止 (1600us)。

2）右下角【方向】滑块：左右拖动，控制小车转向；向左为左转，向右为右转。

3）右侧【云台摇杆】：拖动摇杆控制摄像头云台；左右控制水平角度、前后控制俯仰角度；可点击【云台回中】复位云台。

4）顶部功能按钮：

解锁 / 上锁：解锁后才能下发运动控制指令； 

急停：紧急切断动力，小车立刻停止； 

摄像头切换：可切换主摄像头、副摄像头画面； 

手柄控制：支持外接游戏手柄操控； 

按住说话：网页端语音发送，实现语音交互。

4缓慢拖动油门、方向滑块，测试小车运动；拖动云台摇杆，观察摄像头转动。测试完成后将油门拉至停止位置。

**五、实验收尾**

1 网页端停止小车运动，关闭浏览器。 

2 在 MobaXterm 输入命令退出登录，关闭会话。 

3 断开串口线，关闭小车电源。

## **实验结果**

1、成功使用 USB 串口在 MobaXterm 建立 Serial 会话，登录香橙派系统。

2、使用ip addr show成功查询到无线网卡 IP，顺利建立 SSH 网络远程连接。

3、浏览器访问远程控制网站，WebSocket 正常连接，视频画面实时回传。

4、通过网页滑块与云台摇杆，可以正常控制小车油门、转向以及摄像头云台转动，各项按钮功能响应正常。

## **结果分析**

1、串口连接是底层调试通道，不需要网络，适合初次配置系统；SSH 依赖无线网络，功能更强，是开发调试主流方式。

2、网页控制采用 WebSocket 通信，实现视频画面下行、控制指令上行，不需要安装客户端，任意设备浏览器均可访问操控。

3、车辆控制增加解锁机制与急停按钮，属于安全设计，防止误操作；云台使用独立摇杆控制，实现视觉视角独立调节。

4、油门、转向本质是网页将滑动条数值转换为 PWM 指令，通过网络发送至小车 PCA9685 驱动模块执行电机动作。
