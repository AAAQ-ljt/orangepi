# 小车 /root 官方目录索引

> 本文件用于索引小车 `/root` 下的官方目录和我们的开发目录。
> 整理策略：**官方目录保持原位不动，我们的代码统一放在 `/root/dev`**。

## 官方目录（保持不动）

| 目录 | 说明 |
|---|---|
| `car_Keyboard_Control` | 官方键盘遥控代码（C） |
| `car_Navigation` | 官方导航实验代码（GPS/IMU） |
| `car_Tracking` | 官方 OpenCV 巡线代码 |
| `hardware_Test` | 官方外设测试代码 |
| `opi-control` | 官方网页控制后端（FastAPI/9001） |
| `ParkingVision` | 官方避障停车/模板匹配代码 |
| `SIM8200_for_RPI` | SIM8200 5G 模块驱动/资料 |
| `frp` | 官方 frp + 我们的 frpc-ssh 修改 |
