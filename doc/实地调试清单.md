## 2.5 循迹扫线实跑（蓝板发车 → 循迹 → 再见蓝板停车）

**摄像头固定用下摄 `--camera 2`（云台不参与巡线）**。⚠️ **循迹档已统一到 §2.6 的
`lane_ref_test.py`**：`bench_test.py` 的扫线档随两条旧扫线模块一起归档了，现在它只保留
"转向方向 / 直行基准 / 蓝板发车 / 速度标定"这些**不依赖扫线**的项（见 §2 表格）。

板在车前 → 停（1500us）；移开 → 循迹；再放回正前方 → 停。
**板要摆在下摄的正前方**——发车与停车用的都是下摄这一路画面。

```bash
# ① 先不动电机：确认板能被认到、线能扫到、转向方向对不对
sudo python3 /root/dev/scripts/lane_ref_test.py --no-motor

# ② 正式跑（详细算法与调参见 §2.6）
sudo python3 /root/dev/scripts/lane_ref_test.py --allow-motion --max-seconds 120 \
     --log-csv /root/dev/logs/lane_ref.csv
```

**判据与调参对照表**（跑完看 `--log-csv` 或终端状态行；参数都可用命令行改，不用动代码）：

| 现象 | 看哪个数 | 怎么调 |
|---|---|---|
| 车不动 | 终端的阶段一直是 `(stop)`，或结尾出现"⚠️ 全程没见过蓝板" | 板没被认到：换更大的板 / 摆到下摄正前方更近处；先用 `lane_probe` 确认画面里蓝色占比 |
| 移开板后拱一下就停 | 阶段 `(explore)` 3s 后变回 `(stop)` | 探路窗口里没找到线 → 先按 §1 解决扫线；确需更久可 `--acquire-s 5` |
| 过弯切内道 / 压线 | 误差大时舵机角度不够 | `--kp 0.2`（默认 0.15）、必要时 `--limit-deg 20` |
| 蛇形 / 画龙 | 误差在正负之间来回过冲 | `--kd` 加大（0.12 → 0.3）、`--kp` 调小 |
| 越修越偏（冲出赛道） | 误差单调变大 | **转向方向反了** → `config/site.yaml` 写 `steer_sign: -1`；先用 §2.1 的 `--steer-test` 确认 |
| 速度不合适 | 状态行的 `电调=xxxx us` | 默认 1560（直道 1560 / 大误差 1550）；要更快改 `--speed-us`（死区 1545，调试上限 1600），想保留"直道提速"用 `--speed-fast 15` |

> ⚠️ 跑之前确认：场地空旷、有人在旁能立刻断电；`--max-seconds` 是硬上限；
> 任何退出方式（Ctrl-C / 超时 / 出错）都会**电调归零 + 恢复远程控制阶段**。
> 脚本运行期间**两路推流都会被停掉**（摄像头独占），浏览器看不到画面，靠终端状态行 + CSV 复盘。

## 2.6 参考实现版循迹（`lane_ref_test.py`，推荐先跑这个）

严格按参考实现（`oldCode/src/vision/vision.cpp` + `control.cpp`）写的独立脚本，
不掺我们自己的启发式；仓库里另外两套扫线（`lane_scan.py` / `lane_hough.py`）已归档到 `dev/attic/`。

> §1 的 `lane_probe` 现在也用同一个检测器（并按 `config/site.yaml` 的 ROI 标定），
> 两个工具的读数应当一致——不一致说明参数（`--roi-top` / `--band`）没对齐。

```bash
# ① 只看算法读数（不动电机；本地也能跑：加 --image <图片路径>）
sudo python3 /root/dev/scripts/lane_ref_test.py --no-motor

# ② 正式跑：板在→停；移开→循迹；再见板→停
sudo python3 /root/dev/scripts/lane_ref_test.py --allow-motion --max-seconds 120      --log-csv /root/dev/logs/lane_ref.csv
```

算法（照抄参考实现）：ROI → 灰度 → 高斯 → **Canny(60,140，按边缘数自适应并钳位）**
→ **HoughLinesP(1,3°,50,30,5)** → 斜率 |dy/dx| ∈ [0.25,2] → 按斜率符号分左右、
每侧取代表线 → 前瞻带逐行求中点平均 → error（像素）→ `angle = 90 - (kp·e + ki·∫e + kd·Δe)`
（kp/ki/kd = 0.15/0.01/0.12，限幅 ±15°，输出再平滑 0.7/0.3）→ 误差大时自动减速。

**四处按我们车改过的地方（都已实测标定，其余与参考一致）**：
- ROI 用 `0.35~0.58`（参考是 `0.50~0.85`）：我们下摄太"平"，那个区间里右线已经跑出画面；
- 目标点 `--target-ratio 0.586`（= 画面 375 处；参考是 226/320，那是它自己的安装）。
  另外选线加了"位置锚定"（左线必须在画面中心左侧），否则会把隔壁车道/横向纹理当选；
- **速度**：基准 `--speed-us 1560`（2026-09-20 现场实测 1575 太快），
  参考实现的自适应提速（+15）也一并取消（`--speed-fast 0`），只在误差大时减速 10us，
  且**减速档有下限 = 死区+5us**（`--speed-slow` 给太大也不会掉进死区停车）。

调参（不用改代码）：`--kp/--ki/--kd --limit-deg --target-ratio --roi-top/--roi-bottom-ratio
--band --pick steepest|longest --speed-us --speed-fast --speed-slow --acquire-s`。
