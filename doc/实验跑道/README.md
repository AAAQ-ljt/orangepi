# 实验室跑道（广告纸 7m × 1.4m）

> 建立于 2026-09-16。用途：**在实验室铺一条 1:1 的假跑道，用来测小车程序**（巡线、斑马线停车、停车入库），
> 不用等去现场。尺寸、颜色、元素位置都照规则初稿（`../比赛规则/规则概要.md`、规则 §2.2.1~2.2.3、图 2-2 / 图 9）来，
> 尽量让实验室看到的画面和现场一致。
> **挡板（蓝板）和付款码用实物道具**（团队已有），所以图上不印，停车区只有黄胶带。
> 生成脚本：`gen_lab_track.py`（改参数后重跑即可，产物全部由它生成）。

## 2. 尺寸表（单位 mm，1:1）

```text
整幅 7000（长，沿行驶方向）× 1400（宽）      起点在左端，停车区在右端

宽度方向（从上到下）：
    50   红（白线外侧补的红，把幅宽补到 1.4m）
    40   白线  ← 赛道分界线 = 赛道边缘
  1220   红底（白线内的赛道有效宽度）
    40   白线
    50   红
  ────
  1400

长度方向：
    0      起点（发车端）
 1400      斑马线前缘
 1400~1700 斑马线（长 300）
 6000      停车区入口黄胶带外沿
 6000~6100 入口黄胶带（100 宽）
 6500~6600 中线黄胶带（沿行驶方向，把停车区分成上下两格；中心线 y=700，胶带 100 宽）
 6900~7000 尾端黄胶带（100 宽）
 7000      尾端
```

| 元素 | 几何 | 依据 |
|---|---|---|
| 红底 / 白线 | 红底 1220，白线两边各 40，白线外再补 50 红 | 用户指定（4cm 白边）；外侧红按图 2-2「白线是车道线，外侧还有路面」补 |
| 斑马线 | 前缘距起点 1400；白条 **105（宽）× 300（沿行驶方向）**，条间隙 **105**，共 **5 条**，中间那条压在赛道中线上（中线 y=700） | 规则 §2.2.3：10.5×29.7cm 白纸平铺、间隙 10.5cm、中间那张在赛道中线上。1.22m 内可放 5 张（7 张会压到白线） |
| 停车区 | 长 **1000**（6000~7000）× 赛道宽；黄胶带 **100** 宽（入口 / 尾端 / 中线各一条） | 规则 §2.2.1-4：停车区长度 1 米、宽同赛道、用中线胶带分成上下两格；黄胶带 10cm |
| 挡板（蓝板） | **图上不画，用实物**（40cm 长 × 50cm 高，竖直放在某一格入口） | 图 2-2 + 规则 §2.2.6；裁判随机选一格放板，车停未被遮挡的那格 |
| 付款码 | **图上不画，用实物**（10cm×10cm、与行驶方向成 45°，每格尾部一个） | 规则 §2.2.2；位置按图 2-2（每格尾部） |

颜色（取自规则插图，供店家对色）：

| 部位 | 色值 | 备注 |
|---|---|---|
| 红底 | `#924C4A` | 跑道红。HSV 约 H=1/S=126/V=146，**不会被** `lane_scan` 的白线判据（S≤70）误判为白线 |
| 白线 / 斑马线 | `#FFFFFF` | 纯白，S≈0 满足白线判据 |
| 黄胶带 | `#FEFF00` | 纯黄，HSV 二次校验（停车区黄线）用 |
| 蓝板（实物道具） | `#105FC6` | HSV 约 H=107/S=234/V=198，**正好落在** `settings.START_BLUE_HSV_LOW/HIGH = (95,80,60)~(135,255,255)` 区间内 —— 实物板买/喷这个色最好 |

## 3. 打印说明（把这段话发给广告店）

> 写真 / 背胶，**成品尺寸 7000 × 1400 mm**，**整幅输出、不要拼接**，**哑光（不要覆亮膜）**，
> 四边按尺寸裁切（红色直通边缘，**无出血、无白边**）。
> 文件：`lab_track_7m_1to1.pdf`（1:1 矢量，直接按 100% 输出）。

要点：

1. **幅宽**：成品宽 1.4m > 常见 1.27m 卷材。**必须用 1.52m 卷材整幅出**；若店家只能用 1.27m，
   会沿**长度方向**拼一条缝，缝会落在赛道中间 → 视觉上多一条假"分界线"，**不要接受**。
2. **哑光**：亮膜会镜面反光，摄像头会看到高光（白线检测、黄线/蓝板 HSV 都会被干扰）。
3. **裁切**：外侧 50mm 红条只是补幅宽，边缘裁切误差 ±3mm 不影响使用；若店家坚持要出血，
   把 `gen_lab_track.py` 里 `BLEED_MM` 改成 5 重跑，四边各外扩 5mm 红。
4. **铺装**：地面先扫干净；四边和白线位置用**透明胶带/双面胶**固定（白线 40mm 正好是压胶带的地方，
   别压到红底上，否则会出现一条非赛道色的亮带）。风大或地面滑时注意起步/刹车不要搓动纸面。

## 4. 拿它测什么（与代码的对应）

| 要测的东西 | 怎么用 | 注意 |
|---|---|---|
| 巡线 / 扫线（`vision/lane_scan.py`） | 车放赛道中间，用**下摄 `--camera 2`**，看 `center_x/confidence` | 白线 40mm 在 640 宽画面里够用；`LANE_ROI_TOP_RATIO` 等阈值现场按实际高度调 |
| 斑马线停车（FSM `ZEBRA_STOP`） | 车从起点出发，跑到斑马线前 | 斑马线前缘在 1.4m，起停距离短，油门先小（`ESC_DEBUG_MAX_US`）；规则要求停在**距横道边缘 30cm 内**并停够 10s |
| 停车入库（`PARKING_*`，见 `../专项方案/停车识别与入库方案.md`） | 从停车区入口开进去，**把实物蓝板放在某一格入口** | 板放上格 = "停下面那格"，放下格 = "停上面那格"；板上不要贴反光胶带，颜色按 §2 的蓝 |
| 付款码 | 用实物付款码（10cm×10cm、45°）贴在某一格尾部 | 实验室想测扫码就贴自己的收款码；不想被扫就把背面朝上 |
| 发车逻辑（`vision/start_gate.py`） | 需要**实物挡板**（40×50cm 蓝板）放在车头前，本图不含发车区 | 图上没有发车黄线/挡板，发车测试仍用实物 |

⚠️ 本图是**7m 直道**，只覆盖规则赛道的元素（斑马线 → 停车区），**没有**红绿灯、锥桶、发车/切换区黄线、
弯道 —— 这些要单独准备道具或现场测。

## 5. 改图 / 重新生成

```bash
"E:/venvs/smartcar-ultra/Scripts/python.exe" gen_lab_track.py             # drawio + PDF
"E:/venvs/smartcar-ultra/Scripts/python.exe" gen_lab_track.py --preview    # 另出预览 PNG（需 numpy+cv2）
```

参数都在 `gen_lab_track.py` 顶部（单位 mm）：

| 参数 | 现值 | 说明 |
|---|---|---|
| `LEN_MM` / `LANE_MM` / `WHITE_MM` / `OUTER_RED_MM` | 7000 / 1220 / 40 / 50 | 总长、红底宽、白线宽、外侧红条宽（总宽 = 1400） |
| `BLEED_MM` | 0 | 出血（店家要求时改 5） |
| `XW_X0_MM` / `XW_LEN_MM` / `XW_BAR_MM` / `XW_GAP_MM` / `XW_BARS` | 1400 / 300 / 105 / 105 / 5 | 斑马线位置、长度、条宽、间隙、条数 |
| `PK_LEN_MM` / `PK_TAPE_MM` | 1000 / 100 | 停车区长度、黄胶带宽度 |
| `DRAW_BOARD` / `DRAW_QR` | **False / False** | 是否在图上印蓝板 / 付款码占位（默认不印，用实物） |
| `PK_BOARD_SLOT` / `PK_BOARD_L_MM` / `PK_BOARD_T_MM` | top / 400 / 100 | 打开 `DRAW_BOARD` 时：挡哪一格、板长、图上厚度 |
| `PK_QR_MM` / `PK_QR_ANGLE` / `PK_QR_FROM_END_MM` | 100 / 45 / 300 | 打开 `DRAW_QR` 时：付款码边长、倾角、中心距尾端距离 |
| `C_RED` / `C_WHITE` / `C_YELLOW` / `C_BLUE` | 见 §2 色表 | 颜色 |

改完重跑，drawio 与 PDF 会一起更新；PDF 会自检 xref 并打印 `ok`。

**注意**：drawio 里 1 单位 = 1/100 英寸（和 draw.io 自己的页面设置一致，A4 = 827×1169），
所以 1:1 页是 27559×5512。用 draw.io 导出 PDF 时选 **缩放 100%**，导出后核对页面尺寸是 7000×1400mm；
**更稳妥的做法是直接用本目录的 PDF 去打印**，drawio 只当改图工具。

## 6. 已知差异 / 待现场复核

1. **斑马线条数**：规则只说"中间那张白纸在赛道中线上"，没说几条。这里取 5 条（1.22m 内能放下且为奇数）；
   若现场实际铺了别的条数（或首尾贴到白线上），改 `XW_BARS` 重跑。
2. **付款码位置**：规则 §2.2.2 写的是"位于 2 区域后、中心线上、45°"，与图 2-2 画的两格尾部不一致。
   实物摆放时按**图 2-2**（每格尾部、居中于该格）放；正式规则发布后复核。
3. **外侧红条**：规则插图上白线外确实还有路面（图 2-2 顶部/底部有红），但宽度没有规定，
   这里取 50mm 凑成 1.4m；如现场实测白线外更宽/更窄，改 `OUTER_RED_MM`（同时改总宽）。
4. **实物道具对色**：蓝板按 `#105FC6` 买/喷最稳（落在代码的 HSV 区间内）；黄胶带用纯黄，别用荧光黄。
5. 本图是**示意级 1:1 道具**，不能替代 `../执行路线图.md` §7 的现场几何实测（赛道宽、黄线位置、
   斑马线 30cm 停区、红灯时长 vs 20s 判失败）。
