## 0. 三十秒现状

**项目**：2026 全国大学生智能汽车竞赛 · 室外 5G 远程驾驶无人车赛。Orange Pi 5（RK3588S）+ XT-NetRC 阿克曼底盘 + PCA9685 + 双摄（`/dev/video0`=icspring **云台主摄**（红绿灯用）/`/dev/video2`=Global Shutter **下摄（巡线固定用这一路）**）+ SIM8200 5G。
**目标**：完赛，尽量快。规则致命项：**停车超 20s 不动 = 比赛失败**；罚时：压线 +10s/次、撞锥 +20s、停错/无轮入区 +100s、抢灯 +20s、未停 +50s；**红绿灯等待时长不计入 T有效 → 该等就等**。可靠性优先于速度。

**当前阶段（2026-10-10）**：
- ✅ 已落地：车端骨架（双进程 UDP）、发车（P0-2）、巡线代码（P1-1，**受视角限制不作为完赛路径依赖**）、护栏（单侧±5°/弱对±10°/画龙/跑偏）、锥桶 HSV 检测+S 型绕行（P1-3 部分）、斑马线/红绿灯 HSV/黄区/停车 A-B 元素检测器、IMU（JY901S）驱动、日志降频与语音非阻塞（P1-5）、退出保护安全层（bench_common）。
- 🟡 **当前硬阻塞 = 红绿灯 3 类（off/red/green）标注与补拍 + 操场现场标定**（HSV 主通道 W3 即可通路，灯模型是第二校验通道；标注 1 天 / 训练 1 天）。其余元素全 OpenCV，不依赖标注。
- 📋 **10-11 操场全流程测试**：见 `操场执行单-2026-10-11.md`（循迹 ②③④ 选型、蓝锥 HSV 标定、IMU 实机、元素探针摆位、灯三态补拍、P0-4 几何）。补拍缺口见 `补拍清单.md`。

**动手前必读**：`../AGENTS.md`（仓库根，全部硬性规则/陷阱表/红线的唯一来源）。

### 1.2 双通道融合规则（方案核心）

> 模型通道未就绪时，该元素自动退化为颜色单通道——**单通道永远是合法运行态**；模型到位后升级为双通道校验。

| 元素 | 颜色/几何通道（主，现场可调） | 模型通道（仅灯） | 融合规则 |
|---|---|---|---|
| 发车 | HSV 边沿（已实现） | — | 挡板不进模型 |
| 循迹 | Canny+Hough（4 方案选型后） | — | 模型不参与（车道/分割轨放弃） |
| 斑马线 | 灰度>180 二值化、连通域面积>200 且 ≥4 | — | 纯颜色通道（官方验） |
| 红绿灯 | HSV 红绿互比（H 0-10∪170-180 / 35-85、面积≥500、红>绿）+ 分区二次校验（左 1/3 红 / 右 1/3 绿）、3 帧去抖 | **light3cls**: off/red/green | **两者一致才动作**；不一致→unknown 维持停车（防抢灯）；模型未就绪→HSV 单通道 |
| 锥桶 | HSV+锥度先验+接地点+决策树 | — | 纯颜色通道；防漏检优先（撞锥 +20s） |
| 停车区 | 黄区 HSV 面积≥2500 + 蓝板 HSV 接地点 + **黄区外框中点 vs 蓝板底边中点判左右**（几何，多帧锁定） | — | 纯几何通道；"远距预减速"由 HSV 黄区前向 ROI 检出替代（~~A/B 凸包比~~：2025 上届"停车标志牌"遗产，本届规则只有挡板遮挡机制，不用它） |

- **间隙决策树**（:928-990）：前景带过滤 `bottom.y ≥ 最近锥−145px` → 行分组（均值距 ≤35px）→ 取最近一组 ≥2 锥 → 相邻对找间隙（宽 ≥45px、红色阻挡 `dy∈[−12,+40]`）→ 选"跨越画面中心优先→距中心近→更宽"（:437-468）。

## 2. 元素设计（判据 / 阈值 / 验收）

### 2.1 发车（P0-2 ✅）

- **判据**：蓝板（HSV 蓝色占比 + 近距离大块失焦 + 移板瞬间帧差）。**必须边沿触发**（`vision/start_gate.py`）：
  先确认遮挡（连续 3 帧）→ 武装 → 再等遮挡消失（连续 5 帧）→ 放行。绝不用"当前无遮挡"直接发车（防上电即冲）。
- **FSM 侧独立复核同一逻辑**（不盲信视觉闩锁）；超时只告警不放行。
- 现场标定：`START_BLUE_RATIO_THRESH`（10-10 执行单复验 5/5）。
- 板要摆在下摄正前方、够大够近；跑前查启动日志 `[site]` 行。

### 2.2 循迹（P1-1 ✅ 代码级；视角限制 → 非完赛路径依赖）

> **★ 唯一循迹方案（2026-10-11 收敛定案）**：`lane_ref.py` 边缘法（2026 户外赛官方
> `双线循迹代码.txt` 同源，逐参数一致）。其余循迹代码**全部搁置**：
> `lane_scan` / `lane_hough`（旧版，已进 attic）、`centroid_follow` ②③（操场实测
> 反光拉偏质心，淘汰）、`lane4schemes_probe`（仅留作离线对照工具，不扩展）。
> 2025 上届 opencv 版 `image_handle2`（逐行扫线 + 单侧代边界 + 加权误差）已通读，
> 作为"若 Hough 方案仍不可用"的参考笔记（其 320×96 窄图 + 灰度自适应预处理与本车
> 反光环境不直接兼容，现阶段不实现）。
>
> **★ 帧率结论（2026-10-11 车上实测）**：摄像头 640×480 与 320×240、YUYV 与 MJPG
> 全部锁定 **15.0 FPS**——模组固件硬限制，软件无法提高；`lane_ref` 检测单帧仅
> 3.7ms，处理不是瓶颈。因此官方 30FPS 参数必须做帧率折算（`lane_control.gains_for`
> 已实现 ki/kd ×2 → 0.15/0.02/0.24）。

- **入口/检测**：`scripts/lane_ref_test.py`（现场调试唯一入口，含自检/发车/跟线/落盘/复盘）+ `vision/lane_ref.py`（检测器）+ `control/lane_control.py`（控制器）；10-09 新增质心法实跑 `scripts/centroid_follow.py`（方案②③选型）。
- **算法链路**（lane_ref，与官方 2026 室外赛 demo 逐参数一致）：
  ROI（默认取 site.yaml）→ 灰度 → GaussianBlur(5,5,σ0.5) → Canny(60,140，**同帧自适应**钳位 low∈[20,160]/high∈[40,320]) → HoughLinesP(rho=1, θ=3°, thr=50, minLen=30, maxGap=5) → 斜率先验 |dy/dx|∈[0.25, 2.0] → 按斜率分左右+位置锚定 → 每侧选代表线（--pick steepest/longest）→ 配对宽度闸门 [120,700]px → 前瞻带（默认 y≈168~230）内逐行取中点平均 → `error = center_x − target`。
- **单侧丢线**：`center = 可见侧 x ± 半宽`（WidthPrior 实测中位数/窗口 15 帧）；种子半宽质量压 0.25（<阈值→按维持处理）；推出画面外的中心丢弃。
- **控制**：ErrorFilter（窗口 5/离群 60px=15 误差单位×4）→ PID kp0.15/ki0.01/kd0.12 限幅±15° 平滑 0.7 → `angle = 90 + sign×pid`（`site.yaml steer_sign: -1` 实测正确：角度大=左转）。
- **速度**：基准 1560us；|e|<5 → +0；|e|≥15 → −10；**硬下限 = 死区 1545 + 5 = 1550us**（低于死区车从减速变停车）。
- **护栏（不可删）**：单侧兜底帧 ±5°、弱对帧（一侧≤2段）±10°、画龙（2s 内 3 次 ≥12° 大幅摆动→停车）、跑偏（滤波后误差 ≥60px 持续 1.5s + 同时看原始误差，0=关闭）。
- **丢线阶梯**：质量<min-quality(0.28) → hold 0.6s（沿用上次中心、误差衰减回中位、减速）→ 仍无读数 → 停车；发车后 3s 内一次没见过线 → 低速探路 → 再没有 → 停车。
- **起步前自检**（`_preflight`，自动）：候选带扫描（自动选带）→ 自动前瞻带 → 自动标定目标点（证据弱不采纳、不写 site.yaml：`WEAK_RUN_MAX=20` 行 / 跨距 >25px 判弱）→ 镜头朝向体检（只提示）。
- **质心法备选**：② KP0.6/KD0.1/阈值185；③ KP7/KD3/阈值190（官方 `SERVO_MID−pid_out`，方向不对用 `--sign -1`）；ROI 默认 y 0.25~0.95。离线对照：②③ 40/40 有中心、④ 边缘法 28/40（丢帧=配对宽度 93px）。
- **已知限制（2026-09-19~23 实测）**：下摄"太平"，白线只在画面上部窄带（y≈120~264）且贴左右边缘，近处地面不进视野 → 静止可锁线（误差中位 −1.9px）、动起来易丢单侧（已兜底）；**视角是硬约束，软件解决不了**；完赛主线 = 直线固定舵角+中位微调（site.yaml）、变道/绕锥/入库开环 + 元素检测触发。
- **10-10 现场选型**：②③④ 直道 10m + S 弯（指标=压线/丢线停车/中心跳动）实测定夺。

### 2.3 斑马线

- **判据**：灰度 >180 二值化、连通域面积 >200、**连通域数 ≥4**（官方配方）；ROI 现场标定。
  实跑入口：`lane_ref_test.py --zebra-stop [--zebra-seconds N]`（连续 3 帧触发→停车→停够续走；默认关）。
- 可选形状闸门（`ZEBRA_USE_SHAPE_GATE`，默认关）：条纹扁矩形 + 顶边同排——合成图过度拒绝，现场叠加图标定后再开。
- **行为**：ZEBRA_STOP 停 **≥10s 实测计时**（官方只停 2s 是反面教材）+ 非阻塞播报（audio.py 后台 Popen；设备忙兜底 `lsof -t /dev/snd/*`）。
- 注意：别一看到就断油（会滑过停车点压线 +10s、未停够 10s 再 +20s）——减速停准在 P1-2。

### 2.4 红绿灯（双通道主线）

- **规则与场地**：赛事方在距灯 **1m** 处的跑道侧面放光敏传感器 → 车经过触发 → 灯变红 → 停车等待 → 绿灯通过。灯**横排三灯珠**（红-黄-绿）、赛道上方居中、离地 40cm、"灭灯"=三珠全灭。停车区 = 传感器与灯之间区域，X 轴不得超。
- **光电（P0-3）**：现购仅 20cm，**必须换量程 1.5~2m 漫反射光电开关**（阈值现场可调）；**不要选 E18-D80NK**（上限 80cm 不达标）。必须加超时兜底防死锁。
- **HSV 主通道**：红 H 0-10∪170-180 / 绿 35-85、min_area 500、红>绿判红；**分区校验**：框左 1/3 统计红、右 1/3 统计绿（r_ratio>0.15 且 >2×g_ratio → red；反之 green；否则 unknown）；3 帧去抖。
- **灯模型（light3cls）**：见 §3。融合规则：**两者一致才动作**；不一致→unknown 维持停车。
- **时序（禁止单帧决策）**：等绿灯 = 连续 5 帧 green 且 conf 达标 → 起步（防红→绿过渡帧误判抢跑）；红灯 = 连续 3 帧即可（宁可多等）；off/unknown → 维持停车；超时 T=45~60s 后**策略 A 低速通过**（竞速损失几十秒 << 违规取消成绩）。
- **视觉**：ZEBRA_STOP 后云台抬头到预设俯仰档（≥4m 档1 / 2~4m 档2 / <2m 档3，现场标定，不用连续伺服）；等待时车辆静止 → 低频（5FPS）+ 多帧累积。
- 风险：强光下灯珠对比度极低（采集必须覆盖正午强光）；"红灯长等 vs 停止超 20s 判失败"边界 = P0-4 问官方群。

### 2.5 锥桶（P1-3 部分 ✅）

- **检测**（`vision/cone_detect.py`）：HSV 蓝色连通域（官方穿越火线配方起点 (95,75,55)~(132,255,255)；**V 下限 ≥150 是 2026-09-23 实测必须**——否则暗青蓝环境物全误检：正样本 86.5%/100%、负样本 71%→0% 误检）；闸门 w∈[25,360]、h∈[40,420]、h≥0.5w、面积占比 ∈[0.002,0.15]（挡住近处大蓝板）；`ConeTracker` 进出防抖 3 帧。
- ⚠️ **10-09 C-001 实锤"识别率 0"根因**：`CONE_GATE_ROI` 上沿 0.35 → 锥桶 98.4% 蓝像素在 y<168 被整块切掉。修复候选：HSV (85,55,55)~(125,255,255) + ROI_top=0.05 → 77.5%（`diag/cone_hsv_sweep.py` 网格扫描标定，现场实拍帧定稿）。
- **S 型绕行相位机**（lane_ref_test 主循环，`--cone-avoid` 默认关）：track 中防抖 3 帧有锥 → avoid1（舵角 center±sign×20°，1.2s）→ resume 回正（0.8s）→ avoid2 反向绕 → 回 track；两锥先后触发两轮 = 天然 S 形。绕行期间**豁免跑偏/画龙保护**（故意大幅转向）、保留总上限与再见板停车；绕行油门 `CONE_AVOID_US=1548`（>1545 死区、比循迹慢）。
- `--cone-stop` 实验室模式：检测到就停车（driving=False 不置 stopped），移开自动继续。
- 现场标定项：`CONE_AVOID_DEG/S/CONE_SEGUE_S`（按实车转向半径）、HSV 微调、**确认锥桶在下摄 ROI 内**（先 lane_probe/elements_probe 看）。

### 2.6 停车（P1-4）

- **几何先验法（v2.3 定案，不怕裁判怎么放）**：
  1. `parking_area` 标**整个黄色胶布长方形一个框**（不分成两格——分割线可能被板盖住）；
  2. **中间分割线 = 外框水平中点，在 IPM 俯视图里算**（图像中点 ≠ 地面中点，不做 IPM 必判错）；
  3. **蓝板底边中点（接地线）→ IPM → `board_x`**；在俯视图中与中线比：左半被挡 → 停右半格；目标点 = 空闲半格几何中心；
  4. 近距用 HSV 黄线横向对准（ROI 只在 PARKING 状态启用），纵向黄线 y + 里程（**无编码器 → 时间/IMU 推算，精度差一档**）。
- **参考系双保险**：A. 停车区外框（推荐，外框可见时）；B. 赛道左右边界归一化 `ratio=(cx−x_left)/(x_right−x_left)`（外框不可见时兜底；停车区偏一侧时阈值必须现场标定）。**禁止** `cx < 图像宽/2` 判左右（斜进必错）。
- **降级链**：外框+蓝板（主路径）→ 仅一侧外框边（宽度先验补）→ 单框无板（停它）→ 框内有板（取镜像半格）→ 板压中线 ±容差（用底边横向占用范围判，仍不定回溯更远帧）→ 黄胶布完全不可见（低速搜索+超时保守停）。
- **五阶段**：APPROACH（减速接近）→ SLOT_CONFIRM（连续 7 帧投票+置信度+排除不确定区，**锁定后不切换**）→ ALIGN_TO_SLOT（车位中心线，Pure Pursuit/Stanley/带前馈 PID；**不用检测框直接驱动舵机**）→ ENTER_SLOT（低速入库+限舵角变化率）→ FINAL_STOP（黄线+里程联合判断四轮入区）。
- 场地事实（规则初稿插图已核对）：停车区 = 1m（沿行驶方向）×赛道宽，赛道中线黄胶带分两格，**相对行驶方向左右并排**；蓝板挡在**入口边**。选择"早"：3~5m 一次性决策锁定。
- 验收：板在上格停下面 5/5、四轮入区不压线。

### 2.7 IMU（JY901S）

- **驱动**（`hardware/imu.py`）：UART `/dev/ttyS0` B9600、11 字节帧 `0x55 CID 8B SUM` + 校验和、四通道解码（acc/2048、gyro/16、姿态×0.01、**yaw 无符号 0~360**）、读前 tcflush 抢最新；静态零偏标定 100 样（`acc_bias_z=az−1.0`）；静止判据 |g|<2°/s；无硬件自动降级。
- **用法**：直行纠偏（与 servo_center 互补）、S 弯后方向恢复、仲裁"短时维持 0.3~0.8s"、停车对齐；回正闭环（init_yaw±13~20°、P=30、|误差|<1.5° 连续 3 帧、40s 超时）；**IMU 不可用显式降级开环**。
- 10-10 现场：实机验证接线/波特率（yaw 稳定、静止 az≈1.00g）；failed→B9600→115200 对调检查。

## 3. 数据与模型（模型轨 = 红绿灯专属 light3cls）

> 其余元素一律不走模型；**类别契约唯一来源** = `dev/config/model_profile.yaml` + `code/classes_smartcar2026.txt` + 本文。

- **模型**：YOLO11n 或 YOLOv5s（按官方 13 号教程链路），3 类 `traffic_light_off/red/green`，imgsz **480×640**（摄像头原生零缩放），conf 0.35（profile `light3cls` 已就绪）；导出 ONNX（opset12/simplify/nms off）→ **RKNN 转换由队友负责**（FP16 优先，INT8+校准可选）。
- **数据现状**：红绿灯 571 张（5 片段，按灯态重标 3 类）；全量盘点 2858 张（7 类，其余类不喂模型）。补拍缺口见 `补拍清单.md`（**灯灭态优先**、远距、负样本≥500、停车位多片段、红锥少量）。
- **采集规范**（红绿灯专项）：**录视频不拍单张**（要"灭→红→绿"完整周期）；矩阵 = 4 距离（5/3/2/1m）× 4 光照（**正午强光必拍**）× 3 横向 × 车状态（行驶+静止）；抽帧：切换瞬间前后 1s 每 0.1s 抽 1 帧（**过渡帧单独归档不得丢弃**），稳定期 0.3~0.5s 抽 1 帧；每类目标 ≥400 实例（1:1:1；**近距离 green 必须够多**——那是真正决策帧）；主力用小车云台摄录（输入分布=部署分布）。
- **标注**：LabelImg，**框整个灯箱**（不是灯珠；灭灯也框得住）；同箱所有帧边界一致；模糊/遮挡帧不标但存 hard_cases；**按片段整组切分 8:1:1**（禁止随机——连续帧泄漏→验证集虚高）。
- **训练**：`code/train_light.sh`（--img 640 --batch 8 --epoch 200 --workers 0，5070 Ti；50 轮基准 conf 0.7~0.9）；标注 1 人 1 天、训练 1 天。
- **验证出口**：单类 AP/conf 分布表；上板 15FPS；与 HSV 互比双通道一致率现场报表。
- 风险：灭灯态标不够 → 灭灯误判绿灯抢跑（+50s）；转 RKNN 的 Linux 机依赖队友。
