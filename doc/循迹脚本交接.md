## 4. 算法契约

### 4.1 检测链路（`LaneRefDetector.detect`）

```
ROI（y0=roi_top_ratio*h，y1=(roi_bottom_ratio)*h）
→ 灰度 → GaussianBlur(5,5,σ=0.5)
→ Canny(60,140)，**同帧自适应**：按边缘像素数把阈值往目标区间 [2000,2500] 拉，
  钳位 low∈[20,160]、high∈[40,320]
→ HoughLinesP(rho=1, theta≈3°, threshold=50, minLineLength=30, maxLineGap=5)
→ 斜率先验 |dy/dx| ∈ [0.25, 2.0]（滤掉地面纹理/横向反光）
→ 按斜率符号分左右 + **位置锚定**（左线必须在画面中心左侧，反之亦然）
→ 每侧选一条代表线（`--pick steepest` 取 |k| 最大＝参考实现；`longest` 为备选）
→ 前瞻带 = ROI 上部 `band_ratio=0.6`（看远处），带内逐行求左右线交点、取中点求平均 → center_x
→ error = center_x − target_px
```

**单侧缺失时不输出中心**（`center_x=None`）—— 这是参考实现的行为，也是"单侧不给兜底"的设计；
脚本据此进入 `explore`/`hold`，不会用 0 或画面宽度硬凑中心。

### 4.2 控制链路

```
error（像素）→ ErrorFilter（窗口 5 / 离群阈值 15px，中位数剔离群 + 越新权重越大）
→ pid = kp*e + ki*∫e + kd*Δe（kp/ki/kd = 0.15/0.01/0.12，积分限幅 ±50）
→ angle = 90 + sign*pid   （sign = settings.STEER_SIGN）
→ 限幅 ±limit_deg（默认 15°）→ 输出平滑 angle = 0.7*新 + 0.3*旧
```

- `STEER_SIGN` 语义：**+1 = 角度增大是右转**（与 `control/planner.py` 同口径）。
  车上 `site.yaml` 写的是 **−1**（= 角度增大是左转），于是 `angle = 90 − pid`，等同参考实现原式。
- **2026-09-21 实测确认**：`bench_test --steer-test` 输出 90°→110°→70°→90° 时前轮"先左、后右"
  → 即"角度大=左转" → `steer_sign: -1` **是正确的**。
- 速度：基准 `--speed-us 1560`；`|e|<5` → `+speed_fast`（默认 0）；`|e|≥15` → `+speed_slow`（默认 −10）；
  **硬下限 = ESC_DEADBAND_US(1545) + 5 = 1550us**（低于死区车会从"减速"变"停车"）。

### 4.3 状态机（一帧一步）

```
gate.update(frame)  // StartGate：连续 3 帧遮挡 → 武装；武装后连续 5 帧无遮挡 → 放行
phase = stop    : 未见过板 / 板在 / 探路窗口用尽 / 无有效读数且不在探路窗口 → 电调 1500，舵机 90
phase = explore : 板已移开且距移开 < --acquire-s(3s)：舵角**回中位**，电调 1560，低速往前拱找线
phase = track   : 两侧成对、|误差| < --err-stop-px → PID 输出舵角 + 自适应速度
phase = hold    : 有读数但 |误差| ≥ --err-stop-px → 舵角回中位、低速（**不许照垃圾读数打满舵**）
跑偏保护        : |滤波后误差| ≥ 60px 连续 1.5s（`--err-stop-s`，0=关闭）→ 停车并打印原因
自动标定        : 板未出现（车静止）时取前 6 帧中心的中位数当目标点（`--no-auto-target` 可关）
```

### 4.4 与参考实现（oldCode）的偏离清单（**改动前必读**）

| # | 偏离 | 理由 / 依据 |
|---|---|---|
| 1 | ROI 默认 `0.35~0.58`（参考 0.50~0.85） | 我们的下摄更"平"，0.50~0.85 区间里右线已出画面（2026-09-19 实测） |
| 2 | 目标点用比例且**起步前自动标定**（参考写死 226/320） | 参考的 226/320 是它自己的安装；我们的视角会变，2026-09-21 实测"车摆正时中心 ≈346"而写死的 375 造成恒 −30px 误差 |
| 3 | 选线加**位置锚定**（左线必须在中心左侧） | 否则会把隔壁车道/横向纹理当选（2026-09-19 实验室） |
| 4 | 自适应速度：默认**只减速不提速**（`--speed-fast 0`），且减速档有死区下限 | 用户 2026-09-21 实测 1575us 太快；基准降到 1560 后 "−20" 会算出 1540 < 死区 1545（会把车停住） |

另外**参考实现本身的坑**（它不是教科书）：单侧缺失无兜底、无滤波（我们另加了 ErrorFilter）、
无跑偏保护、无死区概念（那套车的电调标定未知）。移植时保留其形状，但补齐这些安全层。

### 6.2 我（AI）给过的**错误建议**，不要照抄

1. **建议用 `--roi-top 0.55 --roi-bottom-ratio 0.9`**（想靠近参考实现的 0.50~0.85）——错。
   当前视角白线只到 y≈264，0.55~0.9 区间几乎没有白点，只会得到零星线段与 266~320 的假中心，
   实测把车带向左侧冲出赛道。**当前应当用 0.35~0.58**。
2. 早期曾判断"白线根本不在画面里"——不准确：线在画面里，只是在**上部窄带且贴边**。
   真正的问题是"近处看不到 + 贴边"。
3. `bench_test` 的循迹档被归档后仍留了引用（`--steer-test` 被误挡），属归档不彻底。
