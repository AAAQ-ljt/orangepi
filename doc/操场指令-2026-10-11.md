## 3.5 锥桶（先验检测 → S 型绕行；10-11 修复后：绕行已豁免跑偏保护）

```bash
# ⓪ 前置：启动日志必须看到 舵机中位=86.5 转向符号=-1（错了绕行会朝反方向打）

# ★ 顺序（10-11 修）：先拍帧标定，①② 直接用 C-001 候选起步值——
#    settings 默认 ROI(0.35)/HSV 大概率一个锥桶都检不出（离线量化 0~18%），
#    先验/绕行裸跑默认参数会白撞一次"检不出"

# ① 拍帧标定（含负例！误检→幻影绕行比漏检更致命；**人手搬锥桶换 1/2/3/5m**，
#    车不动、--no-motor 不会自己跑）
sudo python3 /root/dev/scripts/lane_ref_test.py --no-motor --no-save-site   --cone-method hsv --cone-stop --save-every-s 0.5 --save-dir cone_1011 --max-seconds 40
#    同机位再拍一组"无锥"负例帧（拍完把锥桶搬走继续拍）
sudo python3 /root/dev/scripts/diag/cone_hsv_sweep.py   --pos-dir cone_1011 --neg-dir <无锥帧目录> --limit 45
#    按扫描结果决定现场参数（或直接用 C-001 候选起步）：
#    --cone-hsv-low "85,55,55" --cone-hsv-high "125,255,255" --cone-roi-top 0.05

# ② 先验检测（C-001 候选起步值）：看终端"锥桶 N 个"打印
sudo python3 /root/dev/scripts/lane_ref_test.py --no-motor --no-save-site   --cone-method hsv --cone-stop --cone-hsv-low "85,55,55" --cone-hsv-high "125,255,255"   --cone-roi-top 0.05 --save-every-s 0 --max-seconds 60

# ③ 检测稳了再绕行（默认保护开着；10-11 已实现绕行期间豁免 —— 预期全程无 guard）
sudo python3 /root/dev/scripts/lane_ref_test.py --allow-motion   --cone-method hsv --cone-avoid --cone-hsv-low "85,55,55" --cone-hsv-high "125,255,255"   --cone-roi-top 0.05   --speed-us 1580 --single-hold --single-speed-us 1580   --max-seconds 120 --save-dir run_1011_coneA
# ③对照：同命令加 --err-stop-s 0（万一仍见 guard，先关保护把 S 走完，回来查豁免是否上车）
# 若"同一个锥桶反复绕"：冷却只是延迟非一次性（S 结束 3s 后又会再触发一轮）——
# 加 --cone-cooldown-s 8~10 即可

# ★ 任务 A（10-11）：三位置矩阵——锥桶分别摆 居中 / 偏左 / 偏右，
#   各跑一遍并记录：① 终端日志"检测到锥桶（偏左/偏右/居中）"选的侧对不对；
#   ② 是否碰锥；③ 绕行耗时。偏左应右绕、偏右应左绕、居中走默认 left。
#   容差 CONE_SIDE_TOLERANCE_PX=60px（settings，现场按画面宽度微调）。
```

**现场覆盖项（10-11 新增，不用改文件）**：`--cone-hsv-low/-high "H,S,V"`、`--cone-roi-top`、
