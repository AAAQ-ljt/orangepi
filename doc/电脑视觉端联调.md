# 电脑视觉端 → 小车控制端 联调说明

> 目标：用一台安装了 `ultralytics` 的电脑运行上一届 YOLO 视觉代码，把感知结果通过 UDP 发送给小车控制端。
> 小车控制端当前支持 dry-run 和 real 两种模式，联调阶段建议先 dry-run。

---

## 一、架构

```text
电脑（视觉端）
  摄像头/图片/视频
    → YOLO 分割
    → JSON
    → UDP（目标：小车 IP:5000）

小车（控制端）
  UDP 监听 0.0.0.0:5000
    → 解析 PerceptionMessage
    → FSM 状态机
    → Planner 生成转向/油门
    → Driver 驱动 PCA9685（real 模式才动）
```

---

## 二、网络准备

### 同一局域网/热点

- 小车 WiFi IP 示例：`10.23.159.43`
- 电脑和小车连同一个 WiFi/热点。
- 在电脑上测试：

```bash
ping 10.23.159.43
```

能通即可。

### 通过公网服务器转发

当前 frp 只转发了 TCP（SSH 2222、网页 8080），**没有转发 UDP 5000**。  
所以公网联调 UDP 需要额外配置 frp UDP 转发，建议先在局域网联调。

## 三、小车控制端启动

### 3.1 Dry-run（安全，不碰硬件）

在车上执行：

```bash
cd /root/dev
PYTHONPATH=/root/dev python3 main.py --dry-run --port 5000
```

实际 `--dry-run` 是默认值，也可以直接：

```bash
cd /root/dev
PYTHONPATH=/root/dev python3 main.py --port 5000
```

### 3.2 Real 模式（轮子架空/安全场地）

```bash
cd /root/dev
PYTHONPATH=/root/dev python3 main.py --real --port 5000 --max-us 1540
```

> `--max-us 1540` 是调试限速，防止速度过快。

---

## 四、电脑视觉端启动

### 4.1 进入上一届视觉代码目录

```bash
cd yolo版本视觉识别/src
```

### 4.2 摄像头模式

```bash
python main.py \
  --camera 0 \
  --model model/best11sseg.pt \
  --udp-ip 10.23.159.43 \
  --udp-port 5000
```

### 4.3 图片/视频模式

```bash
python main.py \
  --source 图片或视频路径 \
  --model model/best11sseg.pt \
  --udp-ip 10.23.159.43 \
  --udp-port 5000
```

## 五、验证步骤

1. 小车先启动控制端（建议 dry-run）。
2. 电脑启动视觉端。
3. 观察小车控制端日志，应该能看见：
   - 收到 UDP 数据；
   - FSM 状态切换；
   - 控制目标输出。

示例日志：

```text
[CTRL] UDP listening on 0.0.0.0:5000
[FSM] WAIT_START -> TRACKING
```

4. 如果小车控制端没有输出，先检查：
   - 电脑能否 ping 通小车 IP；
   - 视觉端 UDP 目标 IP/端口是否正确；
   - 小车控制端是否在监听 5000；
   - 电脑防火墙是否允许 UDP 发送。

## 七、注意事项

- 联调阶段建议先 **dry-run**，确认状态机正常后再 real。
- Real 模式必须在轮子架空或安全场地进行。
- 当前控制端已默认限速 `1540us`。
- 如果视觉端没有 `ultralytics` 环境，需要先在电脑上安装：

```bash
pip install ultralytics torch opencv-python numpy
```
