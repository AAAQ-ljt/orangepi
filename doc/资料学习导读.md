## 1. 学习路线(按顺序)

### 第 1 步:认识小车(0.5~1 天)—— 必读,全队
| 资料 | 看点 | 学会回答 |
|---|---|---|
| `使用教程.md` | 串口连接(1500000 波特)、热点 orangepi/12345678、SSH root/orangepi、外设测试命令、网页控制、键盘遥控、循迹、避障 | 车怎么开机/连接/遥控?镜像里已经有什么功能? |
| `接线图.md` + `接线图\` 配图 | PCA9685 通道 0-3 定义、I2C5、UART0、CH340、GPS→ANT3 | 每个执行器/传感器接在哪? |

### 第 2 步:模块实验(1~2 天)—— 按分工选读
`视频讲解与word实验文档\` 下每个模块 = 1 个 docx + 1 个讲解视频,docx 为主、视频辅助:

| 模块 | 建议角色 |
|---|---|
| 认识香橙派小车 | 全员(快速过) |
| 远程连接和控制(含 5G 图传配置) | 工具/遥测、队长 |
| 摄像头使用模块 | 感知 |
| 键盘控制模块 | 硬件/电控、工具 |
| 循迹模块(视觉黑线 PID) | 控制、感知 |
| 避障停车 | 控制 |
| GPS 模块 / IMU 模块 | 硬件/电控(备用感知源) |
| 语音采集和播放 | 控制(斑马线播报任务) |

### 第 3 步:规则精读(1 天)—— 必读,全队
| 资料 | 看点 |
|---|---|
| `2025规则.md` | 2025 任务链(自主):挡板发车→巡线→弯道 1 锥桶避障→斑马线停 10s+播报→变道→引导锥桶回赛道→AB 停车;罚时细则;计分公式 `(Tmax−T有效)²/(Tmax−Tmin)²×75+扫码5分` |
| `2024规则.md` | 2024 结构:**远程驾驶赛 30 分 + 自主导航赛 60 分 + 技术报告 10 分**;远程驾驶细节(5G 图传、遥控、停车扫码付 0.01)——2026 预计回归,重点读 |

读完后对照着做一张「任务 × 规则要求 × 罚时」速查表(停车时长、播报文案、锥桶数量、压线/撞桶罚时),贴在团队文档里。
